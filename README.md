# Movix-App - Grupo67

**Integrantes:** Angela Anhuaman, Almendra González

**Caso:** Kaiju requiere un sistema claro y actualizado para gestionar el inventario de sus productos, materiales e insumos, permitiéndole controlar las existencias, registrar movimientos y coordinar la reposición.

**Arquitectura:** Kotlin + Jetpack Compose, patrón MVVM.
